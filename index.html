    数据同步（GitHub 仓库存储）

    数据集中存储于本网站所在 GitHub 仓库的 JSON 文件中，任何设备访问均读取同一份数据。请在下方的 db-config.js（与本文件同目录）中填写仓库信息，并在 GitHub 后台生成一个 Personal Access Token (Classic)，勾选 repo 权限。

    说明：填写并保存后会自动从仓库拉取数据覆盖本地；之后所有增删改都会在保存时自动推送回仓库，实现多设备同步。
