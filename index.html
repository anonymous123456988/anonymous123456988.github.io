    数据同步（GitHub 仓库存储）

    数据集中存储于本网站所在 GitHub 仓库的 JSON 文件中，任何设备访问均读取同一份数据。读取为匿名公开访问（任何人可看，无需登录，直接读取 raw 文件 URL，不占 API 配额）；仅后台写入需要 Personal Access Token。
    ★ 安全模型：PAT 不再内嵌到网页源码，而是由管理员在「后台登录」时临时输入，仅保存在浏览器内存（sessionStorage）中，源码里不存在任何令牌 → GitHub Secret Scanning 无法扫描到，永远不会被自动吊销。请使用 Fine-grained PAT（仅绑定本仓库 + Contents: Read and write + 90 天过期）。登录后台后 PAT 自动生效；换浏览器或清缓存后重新登录一次即可。

    说明：填写并保存后会自动从仓库拉取数据覆盖本地；之后所有增删改都会在保存时自动推送回仓库，实现多设备同步。

    📊 访问量也会写入仓库 visit.json（按日期累加），因此「今日访问量」为 A/B/C 任意设备访问的全局汇总，不再只记本机。仓库需存在 data/.keep 以保证目录被 git 跟踪。
